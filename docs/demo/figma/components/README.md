# Original component exports

Unmodified SVG exports from Brew Figma file `NcqNdBhgeg6om2CCZwrYV8`, fetched
2026-11-25 using the asset URLs supplied by design context. These include the
button icon variants, badge leads, toggle states, checkbox mark, input search,
source folder and wordmark point from frames 6:2, 6:35, 6:53, 6:58 and 6:83.
The full original set is retained as a design reference. Live primitive icons
use their original alpha masks at native dimensions so both themes can apply
the correct text/accent color without modifying the SVG geometry.

The separate 53-icon library is in `../icons` and is generated into the inline
sprite from `design/icons.json`.
